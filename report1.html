壱

徳川家康

とくがわ いえやす
没年
元和2年（1616年）
説明
江戸幕府の初代将軍。戦国の世を勝ち抜き、約260年続く幕府の基礎を築いた。
有名な出来事
関ヶ原の戦い（1600年）、江戸幕府の開府（1603年）、大坂の陣（1614〜1615年）
弐

徳川家光

とくがわ いえみつ
没年
慶安4年（1651年）
説明
江戸幕府の3代将軍。幕府の支配体制を整え、将軍を中心とする政治の仕組みを固めた。
有名な出来事
参勤交代の制度化（1635年）、島原の乱（1637〜1638年）、鎖国体制の完成
参

徳川綱吉

とくがわ つなよし
没年
宝永6年（1709年）
説明
江戸幕府の5代将軍。学問を重んじた一方、動物の保護を強く命じたことでも知られている。
有名な出来事
生類憐みの令、湯島聖堂の建立、赤穂事件（在任中）
四

徳川吉宗

とくがわ よしむね
没年
寛延4年（1751年）
説明
江戸幕府の8代将軍。傾いた幕府の財政を立て直そうと、質素倹約と改革に取り組んだ。
有名な出来事
享保の改革、目安箱の設置（1721年）、公事方御定書の編纂
五

田沼意次

たぬま おきつぐ
没年
天明8年（1788年）
説明
10代将軍家治のもとで老中を務めた政治家。商業の力を活かした政策を進めた。
有名な出来事
株仲間の公認と積極的な商業政策（田沼時代）、1786年の老中失脚
六

松尾芭蕉

まつお ばしょう
没年
元禄7年（1694年）
説明
江戸前期の俳諧師。言葉遊びだった俳諧を、芸術性の高い文学へと高めた。
有名な出来事
『おくのほそ道』の旅（1689年）、深川の芭蕉庵での暮らし
七

近松門左衛門

ちかまつ もんざえもん
没年
享保9年（1724年）
説明
浄瑠璃・歌舞伎の作者。町人の恋や義理と人情を描いた作品で、大坂を中心に人気を集めた。
有名な出来事
『曽根崎心中』の初演（1703年）、『国性爺合戦』の大ヒット
八

葛飾北斎

かつしか ほくさい
没年
嘉永2年（1849年）
説明
江戸後期の浮世絵師。90年の生涯で名を何度も変え、風景画から肉筆画まで幅広く描いた。
有名な出来事
『富嶽三十六景』の刊行（1830年代初め）、『北斎漫画』の出版
九

歌川広重

うたがわ ひろしげ
没年
安政5年（1858年）
説明
江戸後期の浮世絵師。叙情あふれる風景画で人気を集め、旅の景色を詩情豊かに描いた。
有名な出来事
『東海道五十三次』の刊行（1833〜1834年頃）、『名所江戸百景』の制作
十

伊能忠敬

いのう ただたか
没年
文政元年（1818年）
説明
商人から天文学・測量の道へ進み、50代で日本全国を歩いて測量した人物。
有名な出来事
蝦夷地の測量に出発（1800年）、『大日本沿海輿地全図』の完成（没後の1821年）
十一

坂本龍馬

さかもと りょうま
没年
慶応3年（1867年）
説明
土佐出身の志士。幕末の混乱のなか、対立していた藩どうしを結びつけるために奔走した。
有名な出来事
薩長同盟の仲介（1866年）、船中八策、京都・近江屋での暗殺（1867年）
十二

勝海舟

かつ かいしゅう
没年
明治32年（1899年）
説明
幕末の幕臣。海軍の整備に力を尽くし、江戸の町を戦火から守る交渉で知られている。
有名な出来事
咸臨丸での渡米（1860年）、西郷隆盛との会談と江戸城の無血開城（1868年）
十三

お芳

およし
没年
不詳
説明
徳川慶喜の妾。側室と表記されることもある。江戸の町火消である新門辰五郎の娘である。徳川慶喜との間に子供はいない。
有名な出来事
大坂城敵前逃亡事件（1867年）
十四

西郷糸子

さいごういとこ
没年数
大正11年（1922年）6月11日 - 大正11年（1922年）6月11日）
説明
西郷の三人目の妻。糸子は再婚。子供は寅太郎・午次郎・酉三。
有名な出来事
西郷隆盛像除幕式
十五

小松帯刀

こまつたてわき
没年数
天保6年10月14日（1835年12月3日）- 明治3年7月20日（1870年8月16日）
説明
薩摩藩の重臣として藩政改革を推進した。西郷隆盛や大久保利通、坂本龍馬らを結びつけ、交渉と調整で明治維新を支えた“幕末の名プロデューサー”。
有名な出来事
薩長同盟（1866年）、藩政改革、禁門の変（1864年）
十六

平賀源内

ひらがげんない
没年数
享保13年（1728年） - 安永8年12月18日（1780年1月24日）
説明
科学者・発明家・作家・起業家を一人で兼ねた、江戸時代屈指の天才・異才。江戸のレオナルドダヴィンチと呼ばれた。
有名な出来事
物産会の開催（1757年）、芒硝（硫酸ナトリウム）を発見（1761年）
十七

華岡青洲

はなおかせいしゅう
没年数
宝暦10年10月23日（1760年11月30日） - 天保6年10月2日（1835年11月21日）
説明
麻酔を用いた近代外科手術を世界に先駆けて成功させた江戸時代の医師。
有名な出来事
世界で初の全身麻酔手術を成功させた（1804年）
